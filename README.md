## Assignment Questions

### Q1 – Searching a Library Catalogue
Implementation of Linear Search and Binary Search using arrays. Comparison counts are analysed for successful and unsuccessful searches.

### Q2 – Sorting the Examination Hall Seating Register
Implementation of Bubble Sort, Selection Sort and Insertion Sort. Comparisons and swaps are analysed for different input arrangements.

### Q3 – Merging Two Merit Lists
Merging two sorted arrays in descending order into a single array without sorting again.

### Q4 – Two-Dimensional Arrays: District Rainfall Records
Processing rainfall data using two-dimensional arrays to calculate annual totals, monthly averages, maximum rainfall and deficient districts.

### Q5 – Processing Text Without the Library
Implementation of word counting, uppercase conversion, string reversal and palindrome checking using character arrays and string functions.

### Q6 – A Directory of Names: Sorting and Searching Strings
Sorting hostel resident names alphabetically, searching names using binary search and identifying duplicate entries.

### Q7 – Design an Election Counting Program
Development of an election counting system using arrays to calculate valid votes, invalid votes, candidate vote counts, winner and tie detection.
